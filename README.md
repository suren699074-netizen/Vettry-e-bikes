# Vettry E-bikes Premium Website

A world-class premium responsive website for Ozotec Electric Vehicle Showroom - Vettry E-bikes.

## 🎨 Design Philosophy

Modern luxury automotive design inspired by Tesla, Porsche, BMW, Rivian, and Apple.

### Color Palette
- **Matte Black**: #0A0A0A
- **Emerald Green**: #00D26A
- **White**: #FFFFFF
- **Dark Grey**: #1A1A1A

### Typography
- Premium modern fonts: Poppins, Sora, Inter

## ✨ Features

- **Smooth Animations**: GSAP + Framer Motion
- **Advanced Effects**: Glassmorphism, scroll reveals, 3D hover effects
- **Responsive Design**: Desktop, Tablet, Mobile
- **Premium UI**: Dark luxury theme with green neon accents
- **Interactive Elements**: Parallax scrolling, floating elements, animated counters
- **Performance**: Lazy loading, fast loading, PWA ready
- **Accessibility**: WCAG compliant
- **SEO Optimized**: Meta tags, structured data

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Build for production: `npm run build`

- **Home**: Hero section with premium showcase
- **Models**: 5 Electric Scooter Models (Flio Pro V2, Flio Max, Flio Neo, Bheem, Bheem Lite)
